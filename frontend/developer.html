Instalasi & Setup Awal

Pastikan Python 3.9+ sudah terinstall. Buka terminal/command prompt di folder project ini. 

# 1. Install semua dependency
pip install -r requirements.txt

# 2. Jalankan backend server
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 3. Buka di browser (tab berbeda)
# User  : file:///path/ke/frontend/user.html
# Dev   : file:///path/ke/frontend/developer.html
💡 HP sebagai Kamera: Install app IP Webcam (Android, gratis) di HP. Pastikan HP dan laptop di WiFi yang sama. Buka app → Start Server → salin URL yang muncul ke halaman User.

Pengambilan Foto Dataset
🎯 Target Foto Minimum
  • 100–200 foto untuk akurasi dasar (~80%)
  • 300–500 foto untuk akurasi produksi (~90%+)
  • Rasio: 80% training, 20% validasi (sudah otomatis di split)
  • Foto dari sudut top-down, jarak kamera tetap (pakai penyangga)
📸 Tips Pengambilan Foto Optimal
  • Nyalakan LED panel di bawah mika — retak akan terlihat lebih jelas
  • Variasikan tingkat kecerahan LED (75%, 100%) agar model robust
  • Ambil foto dari HP dengan resolusi cukup (min 1280×720)
  • Pastikan seluruh mika masuk frame, sedikit ruang di tepi
  • Variasikan orientasi mika sedikit (rotate ±10°) untuk robustness

Anotasi Dataset (Pelabelan)

Anotasi adalah proses memberi kotak (bounding box) di setiap telur dan menandainya egg_good atau egg_cracked. Gunakan LabelImg — tool gratis, export langsung ke format YOLO.

Setiap telur diberi bounding box individual.
🟢 = egg_good  |  🔴 = egg_cracked 
# Install LabelImg
pip install labelImg

# Jalankan LabelImg
labelImg

# Di LabelImg:
# 1. Open Dir → pilih folder dataset/images/train
# 2. Change Save Dir → pilih dataset/labels/train
# 3. Ganti format ke YOLO (klik PascalVOC → pilih YOLO)
# 4. Untuk setiap foto: gambar box di tiap telur
#    → Class: egg_good atau egg_cracked
# 5. Save (Ctrl+S) → otomatis buat file .txt
⏱ Estimasi waktu anotasi: ~5-10 menit per foto (10 telur/foto). Untuk 200 foto = ~20-30 jam. Bagi dengan anggota keluarga/karyawan untuk mempercepat. Alternatif cepat: gunakan Roboflow (online, bisa auto-label).

Struktur folder setelah anotasi:

dataset/
├── images/
│   ├── train/   ← 80% foto (misal 160 foto)
│   └── val/     ← 20% foto (misal 40 foto)
└── labels/
    ├── train/   ← file .txt untuk tiap foto di train
    └── val/     ← file .txt untuk tiap foto di val

# Setiap .txt berisi baris: class_id cx cy w h (format YOLO)
# Contoh: 0 0.45 0.32 0.12 0.18  ← egg_good
#         1 0.78 0.65 0.11 0.17  ← egg_cracked

Training Model
⚙️ Konfigurasi Training (CPU Optimized)
  • Model: YOLOv8n (nano) — tercepat di CPU, cocok untuk 1-3 detik per mika
  • Epoch: 100 (otomatis stop lebih awal jika sudah konvergen)
  • Estimasi waktu training CPU: 30–90 menit untuk 200 foto
  • RAM minimum: 4GB (disarankan 8GB)
# Pastikan sudah di folder root project
# Jalankan training:
python train.py

# Training selesai → model otomatis disalin ke:
# backend/models/best.pt
# Restart backend untuk menggunakan model baru:
uvicorn main:app --reload --host 0.0.0.0 --port 8000
📊 Setelah training, cek folder runs/egg_detector/ untuk grafik akurasi (results.png). Target: mAP50 > 0.85 berarti model sudah siap produksi.

Deploy & Fine-tuning
✅ Checklist Sebelum Produksi
  • Akurasi model (mAP50) > 85% di validation set
  • Uji coba 10+ mika real — bandingkan hasil deteksi vs inspeksi manual
  • Sesuaikan confidence threshold di detector.py jika terlalu banyak false positive/negative
  • Pastikan pencahayaan LED konsisten setiap penggunaan
  • Jaga jarak kamera ke mika tetap sama (pakai penyangga fix)
🔧 Parameter yang Bisa Disesuaikan
  • conf_threshold di detector.py — default 0.45. Naikkan jika terlalu sensitif, turunkan jika miss banyak retak
  • FPS_TARGET di user.html — default 8fps. Kurangi jika CPU terlalu berat
  • CLAHE clipLimit di preprocessor — default 2.0. Naikkan jika LED sangat terang
📈 Cara Meningkatkan Akurasi
  • Tambah lebih banyak foto dataset (target 500+ foto)
  • Foto kondisi gagal deteksi lalu anotasi dan re-training
  • Variasikan kondisi pencahayaan dalam dataset
  • Upgrade ke YOLOv8s (small) jika CPU cukup kuat
